# LikeWise (Likewise Software)

> Likewise Software was a Bellevue, Washington enterprise software company building storage, identity and security products that bridged Linux, Unix and Mac systems into Microsoft Active Directory environments. The company was backed by Trinity Ventures and is listed in that firm's exited portfolio as acquired. It no longer operates: there is no live website, developer portal, documentation, SDK or public API.

## Products (historical, as described on the archived site)

- Likewise Storage Services — OEM SMB/CIFS multi-protocol file access licensed to network storage vendors; named partners on the archived site included HP StorageWorks, Riverbed, EMC Data Domain and NetApp.
- Likewise Data Analytics and Governance — auditing, reporting and governance over unstructured data, with a compliance resource center covering HIPAA, PCI DSS, SOX and FISMA.
- Likewise Enterprise / Likewise Open — Active Directory integration for Linux, Unix and Mac; subsequently part of BeyondTrust.
